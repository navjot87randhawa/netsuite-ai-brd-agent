# NetSuite AI BRD Specialist (Agent 2)

An open-source AI agent designed to automate ERP implementation documentation by converting raw discovery call transcripts into structured NetSuite Business Requirement Documents (BRDs).

## 🚀 What It Does
- Ingests raw meeting transcripts from manufacturing discovery sessions.
- Automatically maps legacy workflows to native NetSuite features (Inventory, Work Orders, WIP, Assemblies) vs. custom SuiteCustomizations.
- Outputs a rigorous, standardized BRD including Scope, Process Flows, Data Integration touchpoints, and Out-of-Scope risk warnings.

## 🛠️ Tech Stack
- Python
- OpenAI API (GPT-4o-mini)
- Open-Source Architecture

## 🔗 Part of a Broader Architecture
This repository contains **Agent 2** of a modular implementation accelerator. **Agent 5 (The Guide & Architect)** is hosted live on MindStudio as an interactive project co-pilot.
